**상태 관리 Hook:**
- `useState`: 컴포넌트에 상태(변수) 추가
- `useReducer`: 복잡한 상태 관리 (useState의 강화 버전)

**부수 효과 Hook:**
- `useEffect`: 컴포넌트가 렌더링된 후 실행할 작업 (API 호출, 이벤트 리스너 등) - 변수 변경 감지 가능

**참조 Hook:**
- `useRef`: DOM 요소에 직접 접근하거나 값을 기억 (리렌더링되지 않음)

**성능 최적화 Hook:**
- `useMemo`: 계산 결과를 기억해서 불필요한 재계산 방지
- `useCallback`: 함수를 기억해서 불필요한 재생성 방지

**컨텍스트 Hook:**
- `useContext`: 상위 컴포넌트의 데이터를 하위에서 직접 사용

**기타:**
- `useLayoutEffect`: useEffect와 비슷하지만 DOM 변경 직후 동기적으로 실행
- `useImperativeHandle`: 부모가 자식 컴포넌트를 직접 조작할 때 사용 (드물게 사용)

**가장 자주 사용하는 순서:**
1. `useState` (거의 필수)
2. `useEffect` (매우 자주)
3. `useRef` (자주)
4. `useMemo`, `useCallback` (최적화 필요할 때)
5. 나머지들 (상황에 따라)

초보자라면 `useState`와 `useEffect`부터 확실히 익히는 것이 좋습니다!
