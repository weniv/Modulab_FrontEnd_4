# branch와 merge

* git branch: 브랜치 목록과 현재 브랜치 확인
* git branch [브랜치명]: 새 브랜치 생성
* git checkout [브랜치명]: 해당 브랜치로 전환
* git merge [브랜치명]: 현재 브랜치에 다른 브랜치의 변경 사항 병합
* git branch -d [브랜치명]: 브랜치 삭제 (병합 완료된 브랜치만 가능)

```
git init
# 파일하나 생성
git add .
git commit -m "one"
git branch
git branch a
git branch b
git branch c
git branch

git checkout a
git branch
# 폴더도 만들고, 파일도 만들고, 이미지도 생성합니다.
# 실제로는 파일 하나만 만들겠습니다. a.txt
git add .
git commit -m "a"

git checkout b
git branch
# 실제로는 파일 하나만 만들겠습니다. b.txt
git add .
git commit -m "b"

git checkout c
git branch
# 실제로는 파일 하나만 만들겠습니다. c.txt
git add .
git commit -m "c"

git checkout main
git branch

git merge a
git branch -d a
# 특이사항: 2번째 merge부터는 메시지 작성을 요구합니다.
# 이 메시지를 요구하는 이유는 병합된 커밋이 여러 개가 될 수 있기 때문입니다.
# 이 메시지를 입력할 수 있는 에디터는 git config core.editor로 설정할 수 있습니다.
# 저는 이 에디터 설정이 VSCode로 되어 있어서 VSCode가 열립니다.
git merge b
git branch -d b

git merge c
git branch -d c

git branch
```
